# Avelis Logo

选定 **方向 3：有依据的 A（Grounded A）**。

## 寓意

A 的几何轮廓建立品牌首字母识别，左侧上行笔画与横向支路把“可追溯路径”收进一个紧凑的标记。支路止于明确的方形依据节点，并与右侧笔画保留间隙，表达答案必须关联依据、经过核验才能继续的边界。图形以路径和负空间表达产品特征，适合克制、严格对齐的数据工作台。

## 文件

- `concept-1.png`：图像生成概念，三个节点构成的可追溯路径。
- `concept-2.png`：图像生成概念，开放边界中的验证勾。
- `concept-3.png`：图像生成概念，几何 A 与依据节点；最终采用的方向。
- `avelis-mark.svg`：无字标、透明背景、`currentColor` 单色图标，`viewBox="0 0 32 32"`。
- `avelis-mark-color.svg`：同一图形，蓝色圆角底板与白色图形，`viewBox="0 0 32 32"`。
- `avelis-logo.svg`：图标与 “Avelis” 水平排列，`viewBox="0 0 120 32"`，图形和字标均继承 `currentColor`。
- `favicon.svg`：与 `avelis-mark-color.svg` 内容完全一致。
- `brand-preview.png`：实际 SVG 的浏览器渲染预览，含深浅背景及 16 / 24 / 32px 尺寸。
- `concept-prompts.txt`：三个概念的完整生成提示词，便于继续探索。

概念 PNG 使用内置 `image_gen.imagegen` 生成，尺寸均为 1254 × 1254px，仅用于方向探索。最终 SVG 根据网格坐标手工编写，由基础路径构成，没有位图嵌入或自动描摹；最终交付应以 SVG 为准。

## 几何构成

- 基准画布：32 × 32 单位。主体范围为 `x=4…28`、`y=5…27`，即 24 × 22 单位。
- A 的外轮廓：顶部平切，顶边从 `(14, 5)` 到 `(18, 5)`；双脚分别落在 `x=4…8.5`、`x=23.5…28`，底边均为 `y=27`。
- 内部开口：顶点为 `(16, 10.5)`；左右笔画平行于各自的内侧边，保持一致的视觉厚度。
- 依据支路：从 `(10, 19)` 起，宽 5、高 2；它与左腿及依据节点重叠，形成连续图形。
- 依据节点：从 `(13, 18)` 起的 4 × 4 方形。节点与右腿最近约有 2.4 单位间隙，在 16px 下约为 1.2px。
- 彩色底板：32 × 32，圆角半径 8，与令牌 `radius-md` 一致；主体不缩放、不移动。
- 横排组合：图标占前 32 单位，字标从 `x=40` 开始。字标采用常见系统无衬线字体 `Segoe UI`、600 字重、26 单位字号、`-0.5` 字距，回退到 `Arial, sans-serif`；无外链字体依赖。系统字体在不同平台上的字宽会略有差异。

## 颜色

所有固定颜色均来自 `../../frontend/design/tokens.json`：

- 品牌底板：`accent` → **`#2F6BEA`**，深浅主题相同。
- 底板内图形：`text-on-accent` → **`#FFFFFF`**。
- 深色背景中的单色图形与字标：建议使用 `text-primary.dark` → **`#E7EBF3`**。
- 浅色背景中的单色图形与字标：建议使用 `text-primary.light` → **`#0E1320`**。
- 预览背景：`bg-canvas.dark` → `#07090E`，`bg-canvas.light` → `#EEF1F6`。

单色文件不硬编码以上主题色，实际颜色由宿主的 CSS `color` 决定。没有采用青色 `signal`，因为该令牌明确保留给血缘图中被选中的列级路径；也没有借用成功、警告或危险状态色。

## 最小尺寸与留白

- 单独图标和彩色应用图标的最小显示尺寸：**16 × 16px**。侧栏推荐 **32 × 32px**，普通界面推荐 24px 起。
- 16px 优先识别 A 的轮廓与开口；此时依据节点更像横向凸起，24px 起能更清楚地读出节点与支路。不要继续缩小或另加细线。
- 横排 Logo 推荐高度 **32px**，最小高度 **24px**，按原始 120:32 比例等比缩放；空间不足时使用独立图标。
- 设图标画布边长为 `S`，四周外部净空至少 **`S / 8`**，推荐 **`S / 4`**。例如 32px 图标，画布之外最少留 4px，推荐留 8px；彩色版从底板边缘计算。
- 横排组合外部净空以其图标画布边长为同一基准，字标右侧也保留相同净空。内部既定间距不压缩。
- 保持等比缩放与原始笔画，不增加描边、阴影、渐变，也不移动节点填满开口。

## 另两个方向为什么未采用

**方向 1：可追溯路径。** 来源到答案的关系直接，但生成稿的上升连线容易被读成趋势或流程图，品牌首字母识别较弱；进一步加入方向箭头和更多节点会增加小尺寸负担。最终保留了单条路径和一个依据节点的结构语言。

**方向 2：依据锚点。** 勾与开放边界能快速传达验证，但更像认证或审核工具的通用标记，也较难自然承载 Avelis 名称。最终采用与 A 一体的节点和间隙表达核验边界。

## 前端接入说明

本次只在 `design/brand/` 内交付文件，未修改前端。

现有 `frontend/src/styles/avelis-ui.css` 的 `.av-rail__logo` 为 32px 方块、8px 圆角，深浅主题通过 `text-primary` 背景和 `bg-canvas` 前景互换。后续接入时，可在现有容器里把文字 “A” 替换为 `avelis-mark.svg` 的**内联 SVG**，沿用容器的 `color` 与背景，并在已有可访问名称的容器内给装饰性 SVG 添加 `aria-hidden="true"`。

如果使用彩色版，则让 `avelis-mark-color.svg` 自带底板，以 32px 方形显示，并移除容器重复的底色。实际资源路径应按前端的静态资源或 SVG 组件方式接入；这里不假定 `design/brand/` 会被 Web 服务直接公开。

注意：外链 `<img>` 加载的 SVG 不会继承页面的 `color`。需要随深浅主题着色时，使用内联 SVG、SVG 组件或 CSS mask；固定彩色版可直接作为图片使用。

favicon 接入示例（先按项目资源约定放入公开路径）：

```html
<link rel="icon" type="image/svg+xml" href="/favicon.svg">
```
