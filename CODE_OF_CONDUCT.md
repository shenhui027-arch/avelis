# Code of Conduct

[English](#english) | [简体中文](#简体中文)

## English

Avelis adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies in all project spaces: issues, pull requests, discussions, and any other channel where someone represents the project.

In short, we expect participants to:

- be respectful and welcoming, regardless of background, identity or experience level;
- give and accept constructive feedback, and focus on what is best for the community;
- take responsibility for mistakes and learn from them.

Harassment, insults, personal or political attacks, publishing others' private information, and other conduct that would reasonably be considered inappropriate are not acceptable.

### Reporting

Report unacceptable behaviour privately to the project maintainer, [@shenhui027-arch](https://github.com/shenhui027-arch), using the contact details on their GitHub profile. All reports are reviewed promptly and handled confidentially. Maintainers follow the Contributor Covenant's enforcement guidelines (correction, warning, temporary ban, permanent ban).

## 简体中文

Avelis 采用 [Contributor Covenant 2.1](https://www.contributor-covenant.org/zh-cn/version/2/1/code_of_conduct/) 作为行为准则，适用于项目的所有空间：issue、PR、讨论，以及任何代表本项目的场合。

我们期望每位参与者：

- 尊重并欢迎他人，不论背景、身份与经验；
- 给出并接受建设性意见，以社区整体利益为重；
- 为自己的错误负责并从中学习。

不接受骚扰、侮辱、人身或政治攻击、公开他人隐私，以及其他通常被认为不当的行为。

### 报告

请通过项目维护者 [@shenhui027-arch](https://github.com/shenhui027-arch) GitHub 主页上的联系方式私下报告。所有报告都会及时、保密地处理。维护者按 Contributor Covenant 的执行指南处理（纠正、警告、临时禁止、永久禁止）。
