- 日期：2026-10-29
- 环境：本机 Docker 演示环境，包括：
  - StarRocks 3.5.14；

## 怎么复现

```bash
uv run scripts/demo.py up
cd backend
uv run pytest                    # 单元测试
uv run pytest -m acceptance      # 全部验收（含 M1 回归）；有 AVELIS_MODEL_API_KEY 时包含真实模型用例
uv run pytest -m "acceptance and not llm"   # 不调用真实模型
```

## 页面

前端 `frontend/`（React + Vite，类型由后端 OpenAPI 生成）。本次只实现了**模型配置页**（`/settings/models`）和应用框架；其他导航页是占位，正式实现在 M3。

在内置浏览器中做了以下验证（1440×900）：
- 登录后，三栏都能读到真实后端的数据。
- 对 `deepseek-flash` 点“检测”：显示“连接正常 · 1967 ms · 支持工具调用”，提供方状态变为“已连接”，时间按业务时区显示。
- 把“问数理解”设为 DeepSeek 并保存：页头从“演示模型”变为“已配置”。
- “添加提供方”抽屉列出 5 个预设。

这次验证中发现并修复了两个问题：
- 检测结果没有写回模型行：原地修改 JSONB 中的字典未被识别为变更。
- 时间被当成本地时间显示：后端返回的时间没有带 UTC 时区。
