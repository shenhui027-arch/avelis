## 走查中发现并已修复的问题

| 问题 | 修复 |
|---|---|
| 指标受影响后，真实模型核对维度取值时拿到空列表，于是改为追问，而不是交给后端说明拦截原因 | 指标不可用时，工具直接告诉模型可以提交意图，后端给出拦截原因。真实模型验收中补了断言 |
| 同一会话里，每条回答的步骤混入了此前各轮的步骤 | 只记录本轮步骤（有断言） |
| 指纹已恢复一致时，影响说明写成“证据不全” | 改为“已恢复为与该版本一致，仍需负责人复核确认” |
| 已无未决事项的变更集一直停在“待处理” | 复核结案后，自动关闭没有未决复核、且影响的指标已不处于受影响状态的变更集 |
| 发布前检查时间没带时区，被当成本地时间显示 | 返回 UTC 时区，按业务时区显示 |
| 界面细节：血缘边“关联”标签过多；检查器标题、SQL 溢出；目录树名称右对齐；关联路径表格溢出；影响范围不显示资产名；导入后记录不刷新 | 已逐项修复 |
